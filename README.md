# 🔐 Hide And Show Password

A simple and user-friendly **Hide and Show Password** feature built using **HTML, CSS, and JavaScript**.  
This project demonstrates how to toggle password visibility using JavaScript to improve user experience and usability in web forms.

🔗 **Live Demo:** *(https://adinath-r-more.github.io/Password-Toggle/)*

---

## 🚀 Features
- 👁️ Toggle password visibility (Show / Hide)
- 🔒 Secure password input field
- ✨ Clean and modern UI design
- 📱 Fully responsive layout
- 🧠 Beginner-friendly JavaScript logic

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the web page  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Toggle password functionality using DOM manipulation

## ⚙️ How It Works
1. User enters a password in the input field  
2. Clicking the **eye icon / button** toggles:
   - Password → Text (Show)
   - Text → Password (Hide)
3. JavaScript changes the input type dynamically
